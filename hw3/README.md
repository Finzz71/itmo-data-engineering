# ДЗ 3. Анализ вакансий PHP-разработчиков

Вариант 5. Потоковый MapReduce и независимый SQL-расчёт в DuckDB по данным из RustFS. Проверка частот навыков, пар и троек, профилирование, анализ зарплат и трёх регионов.

## Подготовка

Проверенная среда — Windows, PowerShell и Python 3.12. Нужен запущенный Docker Desktop с Docker Compose. Команды выполняются из папки репозитория.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
docker compose --profile home up -d rustfs-home
docker compose --profile home ps rustfs-home
```

`compose.yaml` и `hadoop.env` скопированы из ДЗ 2. Для этой работы используется сервис `rustfs-home`.

Веб-консоль доступна по адресу http://localhost:9011, S3 API — http://localhost:9010. Создайте бакет `hh-lake` и загрузите исходный `it_vacancies_2024.csv` в его корень. Исходный датасет берётся из материалов курса. В репозитории он исключён через `.gitignore`.

Скрипты используют Access Key `hhadmin` и запрашивают Secret Key при запуске. Укажите ключ вашего локального RustFS. При первом запуске `duckdb_skills.py` требуется доступ к интернету для установки расширения `httpfs`.

## Правила обработки

- Отбор варианта по отдельному слову PHP в названии вакансии без учёта регистра.
- Навыки разделяются по `;`, очищаются от краевых пробелов, приводятся к нижнему регистру и учитываются один раз в записи. Порядок навыков в сочетании значения не имеет. `php` и `php7` остаются отдельными навыками.
- Зарплатная выборка ограничена `currency = RUR` и `gross = false`. При двух границах берётся середина, при одной — доступная граница. Неположительные значения и обратные интервалы исключаются.
- Минимум для зарплатного сочетания — 30 наблюдений. База пары — более частый навык, база тройки — более частая входящая пара. Частота базы определяется по всей PHP-выборке. При равенстве применяется алфавитный порядок. Базовая группа включает полное сочетание.
- Регионы — Москва, Санкт-Петербург и Новосибирск. Доли навыков рассчитаны по всем PHP-вакансиям региона, медианы — по подходящей зарплатной выборке.
- MapReduce реализован последовательной обработкой порций по 5000 записей. Дополнительная проверка имитирует исключение перед обработкой второй порции и повторяет её в том же процессе.

## Результаты

MapReduce сохраняет три CSV в `s3://hh-lake/results/php/`. Результаты проверки восстановления сохраняются по префиксу `results/php/failure_test/`. DuckDB сверяет полные таблицы частот в обе стороны.

Локальная папка `results/` содержит таблицы зарплатного и регионального анализа. Контрольные числа по выполненному запуску — 5567 PHP-вакансий, 981 навык, 16498 пар и 130599 троек. Зарплатная выборка содержит 2582 записи. Подробные выводы и скриншоты приведены в PDF-отчёте.
